# OttoOS

**Install:** open [assiamahs.github.io/ottoOS/install.html](https://assiamahs.github.io/ottoOS/install.html) in Safari on your iPhone.

Lock screen calendar, reminders and notes for iPhone — on your own photo.

- Pick any photo, OttoOS draws today's events, reminders and Otto notes on it
  and saves it to Photos. Set it as the lock screen wallpaper.
- Lock screen, home screen and StandBy widgets stay live all day.
- Pulls from Apple Calendar, Apple Reminders, and its own "OttoOS" notes list.
- Shortcuts: "Make OttoOS Wallpaper" (for a morning automation) and
  "Add Note to OttoOS".
